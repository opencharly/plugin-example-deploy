# 2026.266.1051 — feat: relocate the check-exampledeploy R10 bed from opencharly/charly

## Summary of changes

Relocate the `check-exampledeploy` R10 witness (and its `exampledeploy` `kind:local` template) from `opencharly/charly`'s `charly.yml` into the plugin's owning repo.

WHY: a check bed must live in the repo that owns what it tests. The check-bed runner's dev-tree override (`proc.SelfSuperprojectOverridePair`, `spec/proc/repo_override.go`) points the bed PROJECT's own superproject's `@github` refs at the local tree. In this umbrella every submodule's superproject is `opencharly/opencharly` (which hosts no candies), so a plugin candy owned by another repo was never exercised as in-development code while its witness sat in `charly`. Relocated here, the template composes the LOCAL plugin candy with no `@github` pin.

**Changed files:**
- `charly.yml` — adds the `check-exampledeploy` bed (deploy `exampledeploy`, `disposable: true`, `lifecycle: dev`, `add_candy: [plugin-example-deploy]`, 4 live host-side probes) composing the LOCAL `plugin-example-deploy` candy; bumps the `version:` stamp `2026.232.0520` → `2026.249.2125`; sweeps the now-false "declares no entities of its own" header comment.
